# NovaCraft Digital

A complete, professional, static website for **NovaCraft Digital**, a student-led web and software development organization created for a university group assignment. The project presents the organization identity, course context, team members, services, workflow, contact form, and GitHub Pages deployment readiness using HTML5, CSS3, and vanilla JavaScript.

- **Group Name:** NovaCraft Digital
- **Course Title:** Web Technologies and Software Development

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages

## Features

- Responsive multi-page website
- Premium glassmorphism visual design
- Modern gradients and custom section dividers
- Mobile navigation menu
- Smooth scrolling
- Scroll reveal animations
- Animated statistics cards
- Advanced card layouts
- Contact form with JavaScript validation
- Success message after valid form submission
- Accessibility-focused semantic structure
- Local image assets for offline and GitHub Pages compatibility
- Software organization content, services, roles, and workflow

## Installation Instructions

1. Clone or download this repository.
2. Open the project folder.
3. Launch `index.html` in a web browser.

No package manager, build tool, or framework is required.

## GitHub Pages Deployment Guide

1. Create a GitHub repository named `cloud-lab-group-project`.
2. Upload all project files to the repository root.
3. Open the repository on GitHub.
4. Go to **Settings**.
5. Select **Pages** from the sidebar.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select the `main` branch and `/root` folder.
8. Click **Save**.
9. GitHub will publish the site and provide a live URL.
